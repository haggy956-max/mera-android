МЕРА — проект Android APK (офлайн)

В проект встроена автономная HTML-версия приложения. Она открывается внутри Android WebView,
работает без подключения к интернету и хранит данные в локальном хранилище приложения.

ВАЖНО: этот архив — исходный проект для сборки APK, а не готовый APK-файл.

Сборка без компьютера через GitHub:
1. На телефоне откройте github.com и войдите/создайте аккаунт.
2. Создайте новый репозиторий (например, mera-android).
3. Загрузите в репозиторий ВСЕ файлы и папки из этого архива, сохранив структуру.
4. Откройте вкладку Actions репозитория и разрешите запуск GitHub Actions, если потребуется.
5. Запустите workflow "Build MERA APK" через Run workflow (или дождитесь запуска после загрузки файлов).
6. После успешной сборки откройте завершённый запуск workflow, внизу скачайте artifact "MERA-debug-apk".
7. Распакуйте скачанный artifact ZIP и установите app-debug.apk. Android может попросить разрешить установку из этого источника.

Для повторной установки APK поверх предыдущей версии подпись должна совпадать. Это debug-сборка,
предназначенная для личного использования, не для публикации в Google Play.

Резервные копии: перед удалением приложения экспортируйте данные из раздела «Данные».
Данные WebView хранятся в частном хранилище приложения и при удалении приложения могут удалиться.
